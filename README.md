## Data summary

The dataset analyzed here is comprised of 573 isolates (413 of which being from Colorado specifically). 

Each isolate is assigned to one of six hosts: domestic cat, domestic cattle, domestic poultry, pet food chicken, wild bird, and wild mammal. Cluster labels A, B, and C are defined by the case investigations. Cluster label are only applied to domestic cat samples. Where disagreements were found between the collection date and the year in the isolate name, year from the isolate name was chosen. 

The eight genome segments of each isolate were pulled from GenBank by BioSample accession and by strain name for those without a BioSample record. Of the 573 isolates pulled, 554 held all eight segments in GenBank. 409 of these samples come from Colorado specifically. 

All analyses were performed twice, once with Colorado isolates alone and once with all of the isolates.

### Script usage

Analysis scripts take either `co` or `all` as an argument for their respective datasets. Results are written into `results/NN_name/<set>`.  

### Script summaries

- The six host groups were derived from the `Host -for phylo` column of the metadata sheet. A cluster label is only assigned to domestic cat isolates. The script compares the collection date with the year in the isolate name and preferentially selects the isolate name's if the two conflict with eachother. Isolate ID is the NVSL number parsed from the name.
- Segments are fetched by a script that looks up each BioSample accession in `nuccore` and falls back to a strain-name search if a BioSample can't be found. Every GenBank record is cached as XML in `data/ncbi-cache`. Every BioSample look-up performed is cached in `data/biosample-cache`.
- MAFFT aligns each segment individually in `--auto` mode. `--adjustdirection` reverse-complements a sequence when doing so would improve the alignment. The script for this also strips the `_R_` prefix added by MAFFT so that the sequence maintains its join to the metadata. The eight alignments concatenate in genome segment order. Supermatrices are not trimmed since SNP count already excludes gaps pair-by-pair. 
- The `IQ-TREE` model is fixed at `GTR+F+I+G4` rather than chosen by `ModelFinder`, since a consistent model keeps the complete dataset, the Colorado subset, and the 26-tip case tree comparable to eachother. IQ-TREE runs partitions (`-p`) with 1000 ultrafast bootstrap replicates and 1000 `SH-aLRT` replicates. The seed is `12345`. `IQ-TREE` alters tip names such that the 554-tip alignment has all spaces converted to underscores. This is corrected for by writing the subset FASTA with a similarly revised label.
- Every tree is rooted at the midpoint by `ha_midpoint_root()`. After rooting, `ape` places the whole stem length on one side. The protocol splits it such that the two basal branches maintain their true lengths.
- Any site where both sequences have bases of either A, C, G, or T and differ from each other are considered a SNP.
- GenoFLU is used for genotype assignment. Isolates are run in parallel, with any isolate lacking a complete set of segments returned as "not assigned". Rare genotypes are grouped as "other" and every assignment is written in `genotypes.tsv`. GenoFLU also confirms cluster letters independently, so the 6 cluster A cats and the 4 cluster B cats are `B3.13` and the 6 cluster C cats are `D1.1`. 

## Alignment and phylogeny 

The eight segments were aligned separately with `MAFFT v7.526` using `--auto`. As a result, MAFFT was permitted to reorient sequences (`--adjustdirection`). We concatenated all eight alignments into a supermatrix in segment order (PB2, Pb1, PA, HA, NP, NA, M, NS). Missing segments were padded with gaps. The final supermatix was comprised of 13,136 aligned positions for the Colorado subset and 14,311 for the full dataset. No trimming was performed. 

Maximum-likelihood trees were inferred with `IQ-TREE v3.1.3` partitioned by segment. A `GTR+F+I+G4` model was applied to every partition. We opted for a fixed model so that the trees for every dataset remain comparable. Branch support was assessed using 1000 ultrafast bootstrap replicates and 1000 SH-aLRT replicates. Branches with SH-aLRT ≥80% and bootstrap ≥95% were considered well supported. Every tree was rooted at the midpoint. For display/readability purposes, we chose to collapse branches <0.5 nucleotide substitutions to polytomies.

## Genotypes

`GenoFLU v1.08` at its default 98% nucleotide identity threshold was used to assign genotypes to all isolates. This requires a concordant call across all eight genome segments. `GenoFLU` assigned `B3.13` to 395 isolates, `D1.1` to 125 isolates, and `B3.6` to 21 isolates. 12 isolates were classified as a rarer genotype, and 1 isolate didn't recieve an assignment. Per-segment lineage assignments generated by `GenoFLU` were used downstream to evaluate reassortment patterns among the isolates.

## Distances and ordination

A single-nucleotide polymorphism (SNP) difference was deinfed as any position at which both sequences had an unambiguous base (A, C, G, or T) and the two bases differ. A pairwise SNP matrix was clustered by UPGMA. Cophenetic correlation between the dendogram and the matrix was `0.999`. We ordinated the same matrix by classical PCoA. The first principal coordinate accounted for 93.7% of all variance because it separates the two main genotypes.

## Sequence variation

A consensus sequence was computed for each genotype of at least 20 isolates, with the majority base at each supermatrix position being kept. Variation was measured against the isolate's own genotype consensus rather than a single consensus covering all genotypes, since genotypes differ across whole genome segments. We considered any site where at least two genomes differ from the consensus as variable. This criterion excludes private changes that comprise most of the raw SNP count. Variable sites were also ennumerated in 200-nt windows. Amino-acid positions were translated from the start codon of the principal open reading frame of each genome segment taken from the GenBank record of a reference isolate for that segment. Spliced products were not translated.

## Nearest neighbor evaluation

For each cat in a given cluster we computed the nearest non-cat influenza isolate by whole-genome SNP distance. A separate maximum-likelihood tree was constructed using those cat isolates and their nearest non-cat isolates so that branch support is reflected in the visualized topology.

## Environment

Every analysis was performed in `R v4.5.3` with `ape v5.8.1`, `Biostrings v2.78.0`, and `ggtree v4.0.5`. Figures were created with `ggplot2 v4.0.3`.
